A [Malha](https://github.com/jnettome/malha) plugin.

```bash
malha plugin add ./path/to/this/folder   # in the project; re-run after every code change

```

What it may do is declared in `malha-plugin.json`; Malha asks before each new kind of request. How plugins work: Malha's `docs/plugins.md`.
